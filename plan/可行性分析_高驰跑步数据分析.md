# 可行性分析：高驰（COROS）跑步数据展示 + AI 复盘产品

> 类型：需求可行性分析（决策级）
> 分析日期：2026-10-08
> 结论定位：**定方向 + 最小验证清单**，暂不写产品代码
> 关联参照：本项目拟复用「微信读书插件」已验证的三段式（官网 / H5 / 小程序）与账户、AI、分享卡能力

---

## 一句话结论

**需求真实，但已不是蓝海。**
- 「高驰官方 App 数据展示不友好 → 用户跑去用第三方」有**真实用户证据**（见第一节），不是我们猜的。
- 但这条赛道已被多个产品验证且拥挤（RQrun / Sigma / 跑鸭 / 佳速通 / Intervals.icu / Runalyze）。
- **最大变量（也是好消息）**：高驰 2026 年 9 月开放了 **自助 MCP + OAuth 2.0**，**个人无需审批**即可让用户授权、读取自己的训练/健康数据 —— 这解决了过去"拿不到数据"的死结。

**推荐路线**：先做「**高驰数据看板（网页 / H5）+ 中文 AI 复盘**」最小版，用**自助 MCP 授权**拿实时数据、**FIT 文件导入**兜底补历史；**先不做小程序**（除非最小验证通过且你愿意走企业主体）。差异必须落在**「展示｜好看」**与**「中文｜本土 AI」**上，不要做"又一个全能跑步 App"。

---

## 一、有没有真实用户

### 1.1 直接证据（用户亲口说"官方 App 不好用，我换第三方"）

- B 站《高驰 Pace2 累计 1.3 万公里测评报告》（2025-04）明确写：
  > "数据显示不够直观。在高驰官方 APP 的跑步明细中，竖幅状态下不能像 RQrun 那样同时显示心率和配速……**我几乎不用高驰官方 APP 看竖幅跑步数据，而是选择使用 RQrun。**"
  → 这是"展示不友好 → 用户外流到第三方"的**一手证据**，且用户外流的目的是"看数据"，正是你要做的事。

### 1.2 官方 App 被公认的短板（第三方评测归纳）

- 无社交：没有社区动态、挑战、排行榜、好友（Coros 自己也不打算做）。
- 跑后不可编辑：不能改爬升、改字段。
- 睡眠精度、安卓 Wi-Fi 同步问题反复被吐槽。
- App Store 用户的评分里"App 体验"一项明显低于"续航/GPS 精度"。

### 1.3 竞品密度 = 需求强度的间接证明

| 产品 | 与中国高驰用户的关系 | 说明 |
|---|---|---|
| RQrun | **支持高驰** | 跑力/训练负荷/体能-疲劳-状况指数；付费会员（超级白金 ¥60/月）；App Store 体育免费榜 Top130 |
| Sigma 跑步 | **支持高驰（已上线）** | 北体大知识库 AI 教练「Sig」；完全免费、无广告 |
| 跑鸭 RunYay | **支持高驰 + MCP** | 数据看板 + AI 复盘 + 计划回写手表；FIT 导入导出 |
| 佳速通 GarSync | **支持高驰** | 35+ 平台同步 + AI 教练 + VDOT/TSB + NAS 备份；5 万+ 下载 |
| Intervals.icu | **官方对接高驰** | 20 万+ 活跃运动员、3 亿+ 活动；免费；被多款 AI 工具当作数据底座 |
| Runalyze / TrainingPeaks | 支持高驰 | 老牌深度分析 |

**需求真实，但"蓝海"已不存在。** 赛道里已经有人把"跑力/负荷/AI 复盘"做完了。

### 1.4 "你的设想" vs 竞品的"反着来的点"是不是真差异？（诚实评估）

| 你的设想 | 是不是真差异 | 说明 |
|---|---|---|
| "专为高驰用户做" | ❌ 不是 | RQrun/Sigma/跑鸭/佳速通**都已支持高驰**；且高驰官方 MCP 让任何 AI 工具都能读高驰数据 |
| "数据展示更好看" | ⚠️ 半 | 可做，但"好看"目前是**主观主张**，缺证据，必须靠最小验证证明（见第五节） |
| "加入 AI 判断与介入" | ❌ 不是 | RQrun/咕咚/Sigma/GarSync 都在做；**高驰官方 2026-09 自己也上了 MCP+AI** |
| **网页/大屏看板** | ✅ **可能是** | 上述产品几乎都是手机 App，**网页端体验普遍弱**——这是唯一还比较空的位置 |
| **中文本土 AI + 微信生态分享** | ⚠️ 半 | 本土 AI 有差异，但国内 Claude/ChatGPT 不便用，需换 DeepSeek/通义等；分享卡你有现成能力 |

> 结论：**差异化空间不大，且正在收窄**（高驰官方在补齐）。生存位在"极简好看的展示 + 网页端 + 中文 AI + 微信分享"这一窄缝里。

## 二、可行路径对比：数据怎么拿（这是全案的关键）

| 路径 | 能力 | 能否实现 | 门槛 | 用户要不要装新东西 | 风险 |
|---|---|---|---|---|---|
| **A. COROS 自助 MCP（OAuth 2.0）** | 读训练/健康/体能数据；**可写课表计划**；单用户 | ✅ 能 | **低**：自服务、**无需申请/审批**、个人可做 | 否（点"连接高驰"授权） | ⚠️ 单用户、**无 webhook（要轮询）**、无 GPX、无双向同步；协议可能调整 |
| **B. COROS Partner API** | 多用户 OAuth、webhook 推送、双向同步、GPX、FIT、1000 调用/min | ✅ 能（更强） | **高**：需"**已具规模的平台** + 注册公司 + 技术代表" | 否 | 冷启动阶段**根本申请不到** |
| **C. FIT/GPX 文件导入导出** | 全量数据（含 GPS/心率/圈） | ✅ 能 | **零依赖** | **要**（用户手动导出再上传，麻烦） | 体验差；但可零风险启动、可补历史数据 |
| **D. 经 Strava 中转** | 基础活动数据 | ⚠️ 半 | 低 | 要绑 Strava | ❌ Strava 条款**禁止第三方通过 API 读取 Strava 同步来的数据**；国内用 Strava 少 |
| **E. 非官方逆向 API**（社区 GitHub 版 Coros MCP） | 拿数据 | ⚠️ 能 | 低 | 否 | ❌ 高驰官方**明确警告会随时失效**；不适合做产品 |
| **F. 用户手填/截图** | 很少 | ✅ 能 | 零 | 要 | 只当兜底 |

**推荐组合：A 为主 + C 兜底。** 自助 MCP 让产品可以"合规、零安装、拿实时数据"；FIT 导入解决"连接前想先看历史数据"的冷启动问题。等做大了再申请 Partner API。

## 三、逐条可行性判定

| 设想 | 能否实现 | 依据 / 条件 |
|---|---|---|
| 做**官网** | ✅ 能 | 静态站即可，成本极低 |
| 做 **H5** | ✅ 能 | 你有现成的 H5 工程与分享卡能力，可复用 |
| 做**小程序** | ⚠️ **半（有条件）** | 需**企业主体 + 小程序备案 + 认证 ¥300/年**；「体育-运动健身」类目一般**不需医疗资质**，但**不得做疾病诊断/医疗建议**，AI 结论须标"仅供参考"。**个人主体类目受限**，机器人/健康数据类功能可能做不了 |
| **AI 判断与介入** | ✅ 能 | 国内用 DeepSeek / 通义等；高驰官方 MCP 也已支持 AI 读数据——**你要做的是"更好懂、更中文、更好看"的解读**，而不是"能读数据"本身 |
| 数据来自**高驰官方合规渠道** | ✅ 能 | 走第二节路径 A；限制是单用户、无推送 |
| 照搬"微信读书扩展那套" | ❌ **不能** | 跑步数据不在浏览器里，**浏览器扩展这一段无用处**；只有「官网 + H5 + 小程序」三段可用 |

**小结**：技术上**能做**；难点在**类目合规（小程序）**与**差异化（AI 已被多方覆盖）**，不在数据获取。

## 四、隐藏坑（预期落差 / 政策时效 / 平台限制）

1. **预期落差**：高驰官方 EvoLab 已提供跑力分数、训练负荷、成绩预测、恢复状态；MCP 又让用户能在 Claude/ChatGPT 里直接问数据。你做"AI 解读"，**可能被官方免费功能覆盖**，这是最大的产品风险。
2. **政策时效（待实测）**：COROS MCP / Partner API 是 **2026 年 9 月**才出的新东西，规则、限流（MCP 的 .FIT 每天限 50 个请求）都可能变。上线前必须复测。
3. **小程序平台限制**：小程序内不能随意打开外部 OAuth 回调页，**必须有后端中转**，并把回调域名加入业务域名白名单；个人主体的类目与能力都受限。
4. **隐私红线**：健康 + 位置数据属**敏感个人信息**，须**单独同意、加密传输存储、可一键删除**；绝不能写进日志或明文上传。
5. **竞争红海**：RQrun / Sigma / 跑鸭 / 佳速通 / 咕咚 全部已支持高驰且已做 AI；任何"通用功能"都会被比价。

## 五、推荐方向 + 最小验证清单

### 推荐方向

- **主线（推荐）**：**「高驰数据看板」网页/H5 + 中文 AI 复盘**。数据走自助 MCP 授权，FIT 导入兜底。定位是**展示层的"放大镜"**，不是又一个训练平台。
- **备选**：只做"AI 复盘能力"，作为插件/服务接入别人已有的跑步平台（不做自己的 App）。
- **兜底（风险最低）**：纯网页版"**跑步数据美化 / 分享卡片**"——只靠 FIT 导入，**不需要实时连接**，先把"好看"这件事做出口碑。

### 先讲清取舍

- 选"自助 MCP"是**技术省事 + 合规**，但受限于单用户、无推送；选"Partner API"是**产品形态正确**（多用户、可推送），但**现在拿不到**。二者常常相反——所以**先用 MCP 起步**，别卡在申请上。
- 选"先做网页"不是技术退让，而是**先用最低成本验证"好看 + AI"是否真有人要**；小程序是**获客形态**，不是验证形态。

### 最小验证清单（不写产品代码即可验证方向）

- [ ] **1. 亲手跑通自助 MCP**：用 COROS 自助 MCP 端点 `https://mcp.coros.com/mcp` + 任一支持 MCP 的客户端，连自己的账号，问"我上个月的训练"。成本 ¥0。
  - 判定：能拉到完整训练+健康数据 = **通过**；只能拉部分字段 = **半通过**；连不上/无权限 = **不通过**。
- [ ] **2. 抱怨征集**：在小红书 / B站 / 贴吧 / 跑友群发帖，征集"高驰 App 数据展示哪里烦"。成本 ¥0。
  - 判定：收到 **≥20 条**且集中在"看不懂 / 不好看 / 不能自定义" = **通过**；<10 条或都是别的抱怨（如搜星慢）= **半通过/不通过**。
- [ ] **3. 重设计效果图比稿**：做 3 张"高驰官方截图 vs 你的重设计"对比图发出去。成本≈时间。
  - 判定：有人主动问"这个在哪能看/怎么用" = **通过**（这是"好看"是真需求的证据）；只有点赞无人问 = **半通过**。
- [ ] **4. 付费意愿问卷**：金数据/问卷星发问卷"你愿意为更好的展示 + AI 复盘付费吗"。
  - 判定：≥30 份且"愿意付费" > 10% = **通过**（说明有商业化空间）；全选"免费才用" = **半通过**（只做免费引流）。
- [ ] **5. 小程序类目实测**：注册个人/企业小程序，试着提交"体育-运动健身"类目。成本 ¥0（备案需时间）。
  - 判定：类目通过且能挂 OAuth 中转 = **通过**；被要求额外资质 = **不通过**（则只做网页/H5）。

> **决策规则**：1 + 2 + 3 通过 → 进入做 MVP；4 通过 → 有付费空间，值得长期投入；5 不通过 → 只做网页 + H5，不走小程序。

## 六、成本速览

| 项目 | 费用 | 备注 |
|---|---|---|
| 域名 | ~¥60/年 | 已有可复用 |
| 网页托管 | ¥0 ~ 极低 | 腾讯云轻量静态目录（已有服务器），你已有部署经验 |
| H5 | ¥0 | 复用「微信读书」H5 工程 |
| 小程序 | 企业认证 **¥300/年** + 备案（免费，1–20 工作日） | 企业主体才稳；个人主体受限 |
| LLM API | 按量，约 ¥1–10 / 百万 token | DeepSeek / 通义等（国内可直连） |
| 高驰数据 | **¥0** | 自助 MCP 免费；Partner API 也免费但需规模 |
| 人力 | 主要是你自己 | 你可复用账户体系、AI、分享卡等现成模块 |

### 合规红线（速查）

- 健康/位置数据：**单独同意 + 加密 + 可一键删除**，不进日志、不明文上传。
- 不得做**疾病诊断/医疗建议**；AI 结论页统一标注"仅供参考，不构成训练或医疗建议"。
- 小程序类目与文案不得出现"治愈/根除/保证 PB"等夸大表述。
