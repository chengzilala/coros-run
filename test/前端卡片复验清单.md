# 前端卡片复验清单（线上 · 需登录）

> **用途**：每次前端部署后，人工点一遍，确认「看板卡片 + 账户页 + AI 复盘」都正常。
> **线上地址**：https://run.chesterlee.cn
> **前置**：用你自己的邮箱登录；手机 / 电脑浏览器均可。
> **说明**：标**【新】**的 = 最近新增的 4 张卡（跑量日历 / 跑量规律&纪录 / 近一周小结 / 下周训练建议），重点看。
> **若线上不是最新前端**：先在本机跑 `bash tools/deploy_web.sh` 再验。

---

## 一、登录与身份
- [ ] 1.1 未登录打开首页 → **自动跳到落地页**（landing.html），不显示任何个人数据
- [ ] 1.2 落地页点登录 → 输入邮箱 →「发送验证码」→ 收到 6 位码（收不到查垃圾箱）
- [ ] 1.3 输入验证码 →「登录 / 注册」→ 回到看板，右上角头像 / 昵称变成你
- [ ] 1.4 登录页点「测试云函数（me）」→ 返回你的 uid / email，不报错
- [ ] 1.5 **刷新页面** → 仍保持登录（无需重登）
- [ ] 1.6 账户页点「退出登录」→ 回未登录；再开首页 → 又跳落地页

## 二、账户页（account.html）
### 绑定 / 同步高驰
- [ ] 2.1 未登录进账户页 → 显示「未登录」，绑定/同步按钮提示「请先登录」
- [ ] 2.2 登录后 → 显示「绑定状态：**已绑定**（区域 us），上次更新 …」或「**未绑定**」
- [ ] 2.3 点「绑定高驰账号」→ 跳高驰授权页 → 授权后能回到本站
- [ ] 2.4 点「同步高驰数据」→ 显示「同步完成：活动 N 条、每日指标 M 条、详情 K 条（用时 …ms）」；绑定状态时间随之刷新
### AI Key（线上 / 本机均可**自填**，加密托管）
- [ ] 2.5 **线上**访问 → 显示「自行填写 · 加密托管」表单：平台按钮（**DeepSeek 默认选中并高亮** / 通义千问 / Kimi / 智谱 GLM / 豆包 / 硅基流动 / 自定义端点）+ API Key 输入框 + 「保存 / 测试连接 / 清除托管 Key」；**「服务地址」「模型名」已自动填好且只读**（旁标「已自动配置」）；点开「还不知道去哪拿 Key」有获取说明
- [ ] 2.5.0 切换平台（如点「豆包」）→ 地址与模型**自动更新、无需手填**；再点「自定义端点」→ 地址与模型清空、**解锁**并聚焦，可手填任意兼容接口
- [ ] 2.5.1 线上填入 Key 点「保存」→ 提示「已加密托管在云端 ✅」；刷新后 API Key 框**平时只显示掩码**（如 `sk-1****abcd`）；点「显示」→ 出现完整 Key（走 `keyReveal`），点「隐藏」→ 立刻清空、回到掩码
- [ ] 2.5.2 线上点「测试连接」→ 返回「连接成功 ✅ 模型回复：…」；Key 留空时用已托管 Key 测试
- [ ] 2.5.3 线上未配置 Key 时去看板「生成复盘」/ 教练 → 提示「去配置 Key」，点击跳到账户页
- [ ] 2.6 **本机**访问 → 同样表单可正常输入；点「显示 / 隐藏」只切换明文，不误触保存
### 数据与隐私
- [ ] 2.7 点「删除我的全部云端数据」→ 弹确认框（红字 · 不可恢复）→ 点**取消不删**
- [ ] 2.8 确认删除 → 提示「已删除…✅」，绑定状态变「**未绑定**」
- [ ] 2.9 删除后回看板 → 不报错（显示引导 / 空态）
- [ ] 2.10 「查看隐私政策」→ 打开 privacy.html

## 三、看板卡片渲染（首页）
> 每张卡的标准：**有内容、图不空、无 `NaN` / `undefined` / 空白**。

### 顶部 Hero
- [ ] 3.1 昵称、副标题（跑量 / 次数概览）、生成时间正常
- [ ] 3.2 今日状态灯（Readiness）显示当前状态；数据不足时**整条隐藏**（不显示空壳）
- [ ] 3.3 KPI 数字与单位正确（km / 次 / 配速 mm:ss / 心率）

### 4 张新卡（重点）
- [ ] 3.4 【新】**跑量日历**：日粒度热力图、按年分块；切换年份（日历上方分段）图随之更新
- [ ] 3.5 【新】**跑量规律 & 纪录**：数据跨度 / 训练天数(占比) / 休息天数 / 平均每周 / 最长连训 / 最长单次 / 最大单日·单周·单月；卡脚有「本月至今 vs 上月同期」「本年至今 vs 去年同期」同期对比
- [ ] 3.6 【新】**近一周小结**：滚动 7 天 vs 前 7 天对比表（跑量/时长/次数/配速/心率/强度占比/负荷）+ 一句点评
- [ ] 3.7 【新】**下周训练建议**：一句总判 + 3–4 条建议；数据不足时整卡隐藏

### 常规卡
- [ ] 3.8 比赛：无比赛时显示引导；「＋计划比赛」/「🏁 标记比赛」能添加，**刷新后仍在**
- [ ] 3.9 跑量趋势：周 / 月 / 年 切换（分段按钮）图更新、卡脚洞察同步更新
- [ ] 3.10 配速 & 心率趋势：近 40 次折线正常
- [ ] 3.11 训练配速（五区）：阈值配速 T、各区分档正确；无数据时隐藏
- [ ] 3.12 训练负荷：短期 / 长期曲线正常
- [ ] 3.13 强度分布（80/20）：近 12 周堆叠柱 + 高强度占比；无数据显示时隐藏
- [ ] 3.14 心率效率：速度 ÷ 心率 折线；无数据显示时隐藏
- [ ] 3.15 活动列表：默认显示若干条，「显示更多」展开全部；点某条 → 弹详情弹窗（× / 点空白关闭）
- [ ] 3.16 卡脚「数据更新于 …」时间正确

## 四、AI 复盘
- [ ] 4.1 选「整体复盘」→「生成复盘」→ 返回中文四段（总览 / 亮点 / 问题 / 建议）
- [ ] 4.2 切「只看最近一次」→ 再生成 → 内容聚焦最近一次
- [ ] 4.3 生成中按钮禁用、显示「AI 正在读你的训练数据…」；完成后恢复可点
- [ ] 4.4 生成成功后弹「今日剩余 N 次」（额度提示）
- [ ] 4.5 超额 / 失败时显示错误 + 「重试」按钮，点重试能再跑
- [ ] 4.6 复盘结果 Markdown 排版正确，切主题后仍正常显示

## 五、交互与持久化
- [ ] 5.1 主题切换 🌙 / ☀️ → 整站与**所有图表**同步换色；**刷新后保持**
- [ ] 5.2 账户页「外观」「字号」档位切换即生效；**刷新后保持**
- [ ] 5.3 顶部吸顶导航：滚动时高亮当前分区；**被隐藏卡片的导航项也隐藏**；点击可跳转
- [ ] 5.4 📸「打卡图」→ 生成 1080×1440 PNG 可下载
- [ ] 5.5 缩放窗口 → 图表自适应，不溢出 / 错位

## 六、边界与协同（易漏项）
- [ ] 6.1 未登录直连首页 URL → 跳落地页（本机与公网表现一致）
- [ ] 6.2 慢网 / 断网 → 显示「读取数据失败…」提示，**不白屏**
- [ ] 6.3 空数据（删数据后）→ 卡片按规则隐藏 / 显示引导，**整页无 NaN**
- [ ] 6.4 多操作不互扰：切完粒度再切主题，图表仍正确重绘
- [ ] 6.5 改主题 / 字号 / 比赛标记后，在页面间来回切换 → 状态保持

## 七、数据一致性抽查（防「看着对、其实错」）
- [ ] 7.1 KPI 的近期跑量 ≈ 活动列表前几条之和（量级一致）
- [ ] 7.2 「近一周小结」的本周跑量 ≈ 跑量日历最近 7 天之和
- [ ] 7.3 某次跑步的配速，在活动列表 / 详情弹窗里一致
- [ ] 7.4 页面内搜关键字 `NaN`、`undefined`（Cmd+F）→ **0 结果**
