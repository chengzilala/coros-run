01 / GET STARTED

快速开始

三件事：登录、绑定高驰、填一个 AI Key。只看图表的话，第三步可以跳过。

  1. 登录统一账户 点顶部「登录」跳到账户中心（account.chesterlee.cn）。一处登录，本站与其它作品通用；首次登录会自动建档。
  2. 绑定高驰（只读） 按提示跳到高驰官方授权页，点一次同意。我们只读取你的训练数据，不会修改你的账号，也不需要你的密码。
  3. 填 AI Key（可选） 到「我的账户 → AI 复盘 Key」填入你自己的 Key，支持 DeepSeek、通义千问、豆包、智谱 GLM、Kimi、硅基流动、文心、MiniMax、阶跃星辰、混元等。填一次即可，之后 AI 复盘和教练都能用。
不填 Key 也能用。跑量、配速、心率、训练负荷、五区配速、比赛与 PB 这些图表都是本地算的，不消耗任何 AI 额度；只有「生成复盘 / AI 教练对话」需要 Key。

线上版与本机版的区别

使用方式适合数据在哪
线上看板（run.chesterlee.cn）手机、平板、公司电脑随时看云端数据库，按你的账号隔离
本机版（127.0.0.1:8920）只在自己电脑上看，数据不出本机本机 web/data/，不上传

本机版怎么启动

在项目目录执行下面两条命令（第一次需要先授权高驰）：

  • COROS_REGION=us python3 tools/coros_probe.py：打开浏览器登录高驰并同意授权（中国区把 us 换成 cn，欧洲区换成 eu）。
  • python3 web/serve.py：启动本机服务，浏览器打开 http://127.0.0.1:8920。

本机版不接管统一账户登录，仍使用旧的邮箱登录方式；数据只落在本机，随时可删。

02 / METRICS

看板指标说明

每张卡片到底在看什么、数字怎么来的，按页面从上到下排。

今日状态灯

顶部那条彩色横条，综合高驰的恢复度、静息心率、HRV 等信号，给出三种状态：

  • 绿 · 状态良好：可以按计划训练，强度课也能上。
  • 黄 · 注意：建议降一点强度，或者把强度课往后挪一天。
  • 红 · 建议恢复：优先睡觉和轻松跑，别硬顶强度。

它是一句「今天该不该练」的提示，不是医疗诊断；身体明显不适时以感受为准。

顶部 KPI

最近 30 天跑量滚动 30 天内的总距离，看近期训练量。
累计跑量账号里有记录以来的总距离。
平均配速所有跑步记录的平均配速，包含轻松跑，所以会偏慢。
平均心率所有跑步记录的平均心率，用来观察整体强度。

跑量日历

一年 53×7 的方格，每一格是一天，颜色越深表示当天跑得越多。它最适合看两件事：训练是否连续、哪里出现了断档。右上角可以切换年份。

跑量趋势

可以切「周 / 月 / 年」三种粒度。虚线是这一段的平均值，用来判断当前是高于还是低于自己的常态。

跑量规律 & 纪录

把训练频率、连续性和个人极值放在一起：数据跨度、训练天数、休息天数、平均每周、最长连训、最长单次、最大单日 / 单周 / 单月，并给出环比与同比（同期对比）。

配速 & 心率趋势

最近 40 次跑步的配速与平均心率曲线。两条线一起看更有意义：配速变快、心率没涨，说明状态在变好。

训练负荷

短期负荷反映最近几天累积的疲劳，长期负荷反映基础体能。短期明显高于长期时，说明最近加量偏快，要注意恢复。

强度分布（80/20）

按周拆分「轻松跑量」和「高强度跑量」，并标出高强度占比。目标是不超过 20%；长期高于这条线，受伤和过度训练的风险会上升。

心率效率

用「速度 ÷ 平均心率」算出的效率值，越高说明同样心率下跑得越快。它只适合和自己比，不同人之间没有可比性。

训练配速 · 五区

按丹尼尔斯（Jack Daniels）的 VDOT 体系，从你的完赛预测推算五区配速：

区间名称感觉用途
E轻松跑能边跑边聊天打有氧基础，占训练量的大头
M马拉松配速有节奏但可持续比赛目标配速，长距离中后段使用
T阈值跑 comfortably hard提升乳酸门槛，常见 20–40 分钟
I间歇呼吸明显急促提升最大摄氧量，400m / 1km 反复
R冲刺很快、很短提升配速与跑步经济性，200m / 400m

地点分布

把带 GPS 的跑步按坐标聚类，自动识别城市 / 区县，统计各地跑量。识别不准的地点可以在「管理地点」里手动改名。

活动列表与单次详情

右侧（手机端在下方）是全部跑步记录。点任意一条，会弹出当次的关键指标和分段配速 / 心率。

打卡图

顶部「打卡图」一键导出 1080×1440 的 PNG，包含状态灯、KPI 和五区配速，适合发朋友圈或存年度记录。

03 / RACES & PB

比赛与 PB

把一次普通跑步变成比赛记录，系统才能算 PB 和比赛专项分析。

两种比赛

  • 已跑比赛：点「标记比赛」，选一条跑步记录，填名称、定位（A / B / C）和目标。定位 A 是主目标赛事，B 是重要热身赛，C 是训练性质的小比赛。
  • 计划比赛：点「＋ 计划比赛」，填名称和日期，卡片上会显示倒计时，方便盯目标。

系统怎么「猜」这是比赛

命中以下信号越多，越可能被识别为疑似比赛，你可以在标记弹窗里一键确认：

  • 距离接近标准比赛距离（5K / 10K / 半马 / 全马）；
  • 配速明显快于你的日常训练；
  • 距离明显长于平时；
  • 发生在周末；
  • 跑步机会减分，因为比赛通常在户外。

个人 PB 怎么归类

按最接近的标准距离自动归类到 5K / 10K / 半马 / 全马 四张表，显示成绩、配速和日期。距离差得太远的记录不会硬塞进 PB 表。

比赛专项分析

完赛卡可以展开分析，主要看这些：

指标怎么看
前半 / 后半程配速后半程掉速越少，配速控制越好。
正负分割后半程比前半程快叫「负分割」，通常是理想跑法。
半程比值 R后半程用时 ÷ 前半程用时，越接近 1 越均匀。
配速波动 CV波动越小，节奏越稳。
心率漂移后半程心率相对前半程的上升幅度，越小越好。
末段撞墙最后几公里是否出现明显掉速。
比赛标记信息按账户码保存在本机 races.json（本机版），不会上传。线上版随账号数据一起存储。
04 / AI

AI 复盘与 AI 教练

两个入口，分工不同：复盘是「看完这次训练给结论」，教练是「可以追问」。

AI 中文复盘

在看板底部选「整体复盘（最近训练）」或「只看最近一次」，点生成。输出固定四段：总览 / 亮点 / 问题 / 接下来 2 周建议。它读的是你已经算好的真实数据，不会凭空编数字。

AI 跑步教练

点右上角「教练」进入独立对话页，可以多轮追问，并切换四种人格：数据极客 / 老教练 / 直球 / 伙伴。同一个问题换人格，回答的语气和详细程度会不一样。

四类问题怎么回答

类型例子依据
自身训练我这周该加量吗？丹尼尔斯体系 + 你本人的看板数据
通用知识什么是乳酸阈值？模型自身知识
事实 / 赛事全马世界纪录是多少？优先引用本地已核验知识，并注明来源
实时信息这周末有什么比赛？如实说明未联网，给官方查询渠道，不编造

另外两个小工具

  • 伤病知识卡：说到膝盖、跟腱、足底等关键词时，给出分级和降级建议，仅供参考，不替代就医。
  • 补给计算器：按体重、时长、强度算碳水 / 水 / 钠，纯本地计算。

Key 与费用

AI 用的是你自己的 Key，费用直接结算给你选的模型平台，不经本站加价。Key 在服务端加密托管，页面和前端拿不到明文；可在「我的账户」里随时更换或清除。平台的公共 Key 默认关闭，不会偷偷消耗额度。

05 / PACE CALCULATOR

配速计算器

输入一个成绩，换回一整套训练配速。

怎么用

  1. 选距离：Marathon / Half Marathon / 10K / 5K / 1500m；
  2. 输入用时或配速，另一项会自动换算；
  3. 看结果：跑力（VDOT）、配速区间、五区训练参考、赛事预测。

输入格式

  • 时间：直接输数字，415 会理解成 4:15，25920 会理解成 2:59:20；
  • 配速：支持 km / mi 切换；
  • 步频与步幅可以互相换算。
计算结果基于丹尼尔斯公式，是训练参考值，不是比赛保证。天气、赛道和当天状态都会影响实际表现。

07 / DATA & PRIVACY

数据来源与隐私

只读、只存自己的、随时能删。

数据从哪来

通过高驰官方 MCP（OAuth 授权，只读）读取你自己的训练数据。区域端点按账号归属选择：中国区 mcpcn.coros.com、北美 mcpus.coros.com、欧洲 mcpeu.coros.com。本站账号属北美 / 国际区，所以命令统一用 COROS_REGION=us。

佳明（Garmin）在接入规划中：其官方接口目前主要面向企业开放，个人授权路径不同，等账号就绪后再开放。

为什么只做高驰和佳明

想把训练复盘做准，需要三件事同时成立：表够专业、用的人够多、数据够开放。高驰和佳明在这三条上都达标；大众智能表偏健康监测，专业训练维度少，数据也更封闭。

数据存在哪

  • 本机版：抓取结果只落在本机 web/data/，不上传；高驰 token 也只存本机。
  • 线上版：训练数据存云端数据库，按你的账号 uid 隔离，别人看不到。
  • AI Key：服务端加密托管，页面与前端都拿不到明文。

你的控制权

  • 只读授权：不会修改你的高驰账号，也不会代你发布任何内容。
  • 一键删除：在「我的账户 → 数据与隐私」可以删除自己的全部云端数据，二次确认后不可恢复。
  • 不采集、不广告：没有第三方统计脚本，也没有广告 SDK。
08 / FAQ

常见问题

点开看答案。

登录后看板没有数据 / 一直是空的？

先确认两件事：一是在「我的账户」里高驰是否显示已绑定；二是绑定后是否等同步完成（首次同步需要一点时间）。如果刚绑定就打开看板，刷新一次即可。仍然为空的话，重新授权一次高驰。

为什么 AI 说「我未联网」？

这是如实说明。AI 教练不接实时网络，赛事报名、临时改期、天气这类信息它不会编，会给你官方查询渠道。训练数据相关的回答不受影响，因为数据已经在看板里。

手机上怎么像 App 一样打开？

用手机浏览器打开 run.chesterlee.cn，登录后选择「添加到主屏幕」。之后从桌面图标进入，就是全屏的 H5 看板，不需要应用商店。

数据多久更新一次？

看板读取的是同步后的数据。线上版在登录后按需同步；本机版每次运行抓取命令时更新。刚跑完的记录如果还没同步，等一会儿再刷新。

能把数据导出吗？

可以导出「打卡图」（PNG，1080×1440）。原始训练数据属于你的高驰账号，可以在高驰官方渠道导出；本站不额外提供批量导出。

AI Key 会不会泄露？

Key 在服务端加密存储，页面和前端拿不到明文；日志里也不会打印。你可以在「我的账户」里随时更换或清除。建议使用单独的 Key 并设置额度上限。

训练建议能当医嘱吗？

不能。所有配速、负荷、伤病提示都是训练参考。出现持续疼痛、胸闷、眩晕等情况，请停止训练并就医。

09 / BRAND

名字与 logo

「跑不快」不是自嘲，是一句训练观：慢就是快。

跑不快 SLOW IS FAST

名字的由来

慢就是快（Slow is fast）——跑得慢，才跑得久；跑得久，才跑得快。所以叫「跑不快」：跑不快，才跑得快。

图标为什么是一条线

  • 一条配速线：像看板里的配速曲线，也像一段跑动轨迹；不画跑鞋、不画手表，避免和别的运动 App 撞脸。
  • 先沉后升：线条先向下沉，再向上冲。下沉的那一段不是失误，是刻意留的——慢的那一段，换来后面的高度。
  • 一个橙点：线的尽头是「此刻的你」。数据一直在涨，但人只站在今天这一格。
