# 跑者膝（髌股疼痛综合征）

keywords: 膝盖, 膝盖疼, 髌骨, 髌股, 跑者膝, 下楼疼, 上下楼, 膝前

- **典型表现**：膝盖前方 / 髌骨周围钝痛，久坐、上下楼、下坡跑时加重；跑开可能缓解，但跑完或次日又痛。
- **常见诱因**：跑量或强度骤增、臀中肌与股四头肌力量不足、下坡与落地冲击偏多。
- **自我处理（按程度分级）**：
  - 轻微（跑中可忍、跑后不加重）：减量 30–50%，暂避下坡与速度课，加强臀腿力量；
  - 明显（跑中已改跑姿 / 跑后持续痛）：停跑 3–7 天，改骑车、游泳维持有氧；
  - 加重（日常走路也痛、肿胀）：尽快就医。
- **常见误区**：靠护具硬顶、继续下坡跑、只拉伸不练力量。
- **一句话**：多数跑者膝靠「减量 + 练臀腿」能缓解，但别带痛硬练。
