# 赛事评级 · 大满贯 · 选手等级

keywords: 赛事评级, 金标, 银标, 铜标, 白金标, 精英标, 标牌, CAA, 田协, 认证赛事, A1, A2, B类, 大满贯, 六星, 六大满贯, 七大满贯, 大众等级, 大众选手等级, 精英级, 专业等级, 运动健将, 一级运动员, 运动员等级

- **赛事评级两套体系**：中国田协 CAA（金标 / 银标 / 铜标；A1 / A2 / B 类认证）｜世界田联 WA（白金标 / 金标 / 精英标 / 标牌，Label Road Races）。
- **认证的意义**：只有在中国田协 **A1 类**认证赛事中取得的成绩，才能申报大众选手等级、并计入官方排名。
- **世界马拉松大满贯（AbbottWMM）七场**：东京、波士顿、伦敦、柏林、芝加哥、纽约、悉尼（悉尼 2025 年加入；开普敦已确认 2027 年 5 月起成为第八场）。
- **六星奖牌（Six Star）**：完赛最初六场大满贯（东京 / 波士顿 / 伦敦 / 柏林 / 芝加哥 / 纽约）即可获得。
- **大众选手等级**（2024 版）：全马、半马分精英级 / 一级 / 二级，按 8 个年龄组（≤34、35-39、40-44、45-49、50-54、55-59、60-64、65+）划分，须在 A1 类赛事达标。例：男子全马 34 岁以下组——精英级 3:00:00、一级 3:30:00、二级 4:00:00。
- **专业选手等级**：国际级运动健将 / 运动健将 / 一级 / 二级 / 三级（国家体育总局《运动员技术等级标准》，自 2025-01-01 起实施）。
- **来源**：中国田协（athletics.org.cn）、世界田联（worldathletics.org）、AbbottWMM（worldmarathonmajors.com）。
- **时效提示**：评级与纪录会更新，具体以官方最新公告为准。
