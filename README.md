# 跑不快（本机自用版）

> **名字的由来**：慢就是快（Slow is fast）——跑得慢，才跑得久；跑得久，才跑得快。所以产品叫「跑不快」：跑不快，才跑得快。

把你的高驰（COROS）训练数据，做成一个自己看得顺眼的**数据看板**：跑量/配速/心率趋势、单次详情、以及 **AI 中文复盘**。
第一版**只在本机跑、只给自己看**。

> **域名 / 备案 / 上线**：统一记在 [部署上线备案/README.md](../部署上线备案/README.md)（唯一台账），本文不重复；线上页脚已挂 `陇ICP备2026009894号-2` + `甘公网安备62052302000062号`（含公安部官方图标，2026-10-28 通过）。

## 它长什么样
- 顶部：品牌 + **「工具」下拉**（配速计算 / 知识库 / 思考 / 官网 / 帮助 / 我的账户 / 打卡图 / 主题切换都收进去，首屏不再堆按钮）
- **首屏「今日状态」**：左边**恢复度环**（高驰恢复度 %；佳明用厂商训练准备度分数；没有信号就不画数值），中间是**今日结论 + 昵称/设备/体能**（VO2max / 跑力值 / 阈值配速 / 完赛预测），右近**7 天每日跑量柱** + 教练 / 登录入口
- KPI：最近 30 天跑量、累计跑量、平均配速、平均心率——每张卡带**环比**（近 30 天 vs 前 30 天：跑量 %、配速快慢秒数、心率 bpm），跑量卡另有**近 7 天迷你柱**
- **跑量日历**：日粒度热力图（一年 53×7 方格，色深=当天跑量），一眼看训练密度与断档
- **跑量多维度**：跑量趋势可切**周 / 月 / 年**；另有「**跑量规律 & 纪录**」卡——数据跨度 / 训练天数 / 休息天数 / 平均每周 / 最长连训 / 最长单次 / 最大单日·单周·单月，含**环比·同比（同期对比）**
- **近一周小结**：顶部宽卡，滚动 7 天窗口——最近 7 天 vs 前 7 天对比（跑量/时长/次数/配速/心率/强度占比/负荷）+ 一句点评
- **下周训练建议**：一张教练建议卡——按最近 7 天数据用规则生成总判 + 3–4 条建议（加量/保持/减量/恢复/强度/频次/配速），不填目标也能用
- 三张图：**跑量趋势**（周/月/年，含均值基准虚线）、**配速 & 心率趋势**（近 40 次）、**训练负荷**（短期/长期）
- **强度分布（80/20）**：按周堆叠柱——轻松 vs 高强度跑量，标出高强度占比（目标 ≤20%，含目标线 + 洞察脚注）
- **心率效率**：`速度 ÷ 平均心率` 折线（同类只比同类，含均值线），看同心率下是否跑更快
- **训练配速 · 五区**：按丹尼尔斯 VDOT 推算 E/M/T/I/R 五区配速（由完赛预测换算）
- 活动列表：点任意一条，弹出**单次详情**（关键指标 + 分段配速/心率）
- **AI 中文复盘**：基于你的真实数据，输出「总览 / 亮点 / 问题 / 接下来 2 周建议」
- **🏁 比赛模块**：看板首个分区「比赛」——把某次跑步记录**一键标记为比赛**（名称 / 定位 A·B·C / 目标），或「＋ 计划比赛」加一场带**倒计时**的目标赛；**系统会自动识别疑似比赛**（命中标准距离 + 明显快于日常 + 超长距离 + 周末，跑步机减分），在标记弹窗里一键确认；完赛卡可展开**比赛专项分析**（前半/后半程配速·心率、正负分割、半程比值 R、配速波动 CV、心率漂移、末段撞墙），并按标准距离自动归类**个人 PB 表**（5K/10K/半马/全马）。标记信息按账户码存本机 `races.json`，不上传
- **🏃 AI 跑步教练（丹尼尔斯内核 · 跑步万事通）**：看板右上「🏃 教练」进入**独立对话框**，可多轮追问、切换四种人格（数据极客 / 老教练 / 直球 / 伙伴）。按**四类问题分工**作答：① **自身训练类**——以杰克·丹尼尔斯跑步公式为内核（五区配速 / 80-20 强度 / 10% 递增 / 周期化），直接引用看板已算好的数字；② **通用知识类**（训练原理 / 配速心法 / 装备 / 饮食常识）——用自己的知识直接答；③ **事实 / 赛事类**（世界纪录 / 赛事评级 / 大满贯 / 等级标准）——优先引用**本地已核验知识**并注明来源；④ **实时类**——如实说明「我未联网」，给出官方查询渠道、**绝不编造**。另含**伤病知识卡**（关键词命中给分级 + 降级建议，仅供参考）与「**🧮 补给计算器**」（按体重/时长/强度算碳水·水·钠，纯函数计算）；只读数据、不回写手表
- **📸 打卡图**：一键导出 1080×1440 PNG（含状态灯 + KPI + 五区配速）
- **⏱ 马拉松配速计算器**：看板右上「⏱ 配速计算」进入独立页（复刻高驰「配速计算」）——选距离（Marathon / Half Marathon / 10K / 5K / 1500m）+ 输入用时或配速，即时得出**跑力（VDOT）**、**配速区间**（1km/1Mile/800m/400m）、**五区训练参考**、**赛事预测**；支持数字式输入（415→4:15、25920→2:59:20）、配速 km/mi 切换、步频↔步幅互算
- **📚 跑步知识库**：看板右上「📚 知识库」进入独立页——列表（**常用跑步网站**〔置顶〕 / 赛事组织和评级 / 大众马拉松选手评级 / 专业马拉松选手评级 / 短中长跑世界纪录 / 路跑世界纪录 / 世界马拉松大满贯 / 赛事认证与赛道丈量）→ 点开看详情：**赛事组织与两级评级体系**（中国田协 CAA / 世界田联 WA）、**大众选手等级表**（精英/一级/二级 × 8 年龄组）、**专业选手等级表**（国际级/运动健将/一~三级）、**短中长跑世界纪录表**（场地）、**路跑世界纪录表**（5K/10K/半马/全马）、**世界马拉松大满贯**（七场赛事 / 六星奖牌 / 精英积分）、**赛事认证与赛道丈量**（中国田协 A1/A2/B/C + 世界田联赛道标准 / AIMS 丈量）、**常用跑步网站**（官方机构 / 赛事大满贯 / 越野 / 本站工具的可点击链接集合）；**每条内容底部都列出官方来源链接做背书**（中国田协 / 国家体育总局 / 世界田联 / AIMS / AbbottWMM）

## 一、首次准备：跑通授权（只需一次）

> 环境要求：macOS + Python 3。**无需安装任何第三方库。**

```bash
cd coros-run

# 1) 授权：会自动打开浏览器，登录你的高驰账号并点同意
#    注意：账号在「北美/国际区」用 us；中国区用 cn；欧洲区用 eu
COROS_REGION=us python3 tools/coros_probe.py
```

- 授权成功后，本机会生成 `.coros_token_us.json`（凭据，已在 `.gitignore` 中，**不会被提交**）。
- 如果报「Client authentication credentials missing…」，多半是**区域选错了**，换 `cn` / `eu` 再试。

### 佳明（Garmin，本机自用 · 已实测跑通）

佳明走**非官方 Connect 库**（`garminconnect` + `garth`）——这是本项目「零第三方依赖」的**唯一破例**，**仅限本机抓数脚本**：

```bash
cd coros-run
# 1) 一次性的专用虚拟环境（国区实测锁 0.2.40）
python3.12 -m venv .venv-garmin
.venv-garmin/bin/python -m pip install "garminconnect==0.2.40" -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3) 抓数（中国区必须带 GARMIN_REGION=cn）
```

- ⚠️ 中国区登录已改走**新版 SSO 门户**（旧的 `/sso/embed` 表单流程会 401），脚本里由 `_portal_login_cn()` 处理，无需手动操作。

## 五、账户体系（本机自用：账户码即账号）

> 心智：**账户码 = 账号 + 登录凭证（一体），本机唯一持有**。没有注册/密码——浏览器首次访问自动生成一个 32 位随机串当你这个账户。

- **账户码**：在「我的账户」页默认显示掩码，点「显示完整」可看全、可一键复制。**请抄好它**——退出登录后本机不再持有。
- **AI Key 托管**：填 Key 后**加密存本机**（`web/data/accounts.json`，密文外壳 `v1:<nonce>:<tag>:<ct>`），页面平时只显示掩码；**点「显示」** 才向本机服务要一次明文（`keyReveal`，用于核对/复制），点「隐藏」即清掉、不在页面停留。机器密钥在 `web/data/secret.key`（权限 600，自动生成、不入库）。
- **跨设备登录**：在「我的账户 → 跨设备登录」生成 **6 位一次性码**（10 分钟、用一次失效），在另一台设备输入即可登录同一账户；也可直接**粘贴 32 位账户码**。
- **退出防呆**：点「退出登录」会先弹出**完整账户码 + 一键复制**，确认已保存后才退出。

## 安全与隐私
- 高驰 token、大模型 Key、抓取到的个人训练数据，**全部只在本机**，且都已在 `.gitignore` 中。
- 本工具对高驰数据**只读**，不会修改你的账号。
- **线上版**：数据存腾讯云 CloudBase，按登录账号隔离（只有本人可见）；高驰令牌加密入库；可在「我的账户 → 数据与隐私」**一键删除全部云端数据**，详见 [隐私政策](web/privacy.html)。
